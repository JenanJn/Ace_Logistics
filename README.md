ACE Logistics

A Role-Based Logistics Management System

📌 Introduction

ACE Logistics is a web-based logistics management application designed to streamline transportation services including truck, air, and ship cargo. It provides a centralized platform for efficient interaction between customers and administrators.

The system implements secure authentication with email verification and password hashing, along with role-based access control for better security and management.

⚙️ Features
👤 Customer
Book logistics services (Truck, Air, Ship)
Track orders
Manage personal details
🛠️ Admin
Manage customers and orders
Control website content
Dashboard for monitoring activities
🔐 Security
Secure login system
Email verification
Password hashing
🧰 Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
Server: XAMPP

🚀 How to Run the Project
Install XAMPP

Move project to:

C:\xampp\htdocs\
Start Apache and MySQL in XAMPP
Import the database into phpMyAdmin

Open browser and go to:

http://localhost/ace_logistics
